# goit-algo-hw-10

Домашня робота №10 — жадібні алгоритми, динамічне програмування та метод Монте-Карло.

## Структура

- [`task_01/`](task_01/) — **Завдання 1.** Видача решти: жадібний алгоритм vs динамічне програмування. Порівняння за часом виконання і точністю на наборі монет `[50, 25, 10, 5, 2, 1]`.
- [`task_02/`](task_02/) — **Завдання 2.** Обчислення визначеного інтеграла $\int_0^4 \sin x\,dx$ методом Монте-Карло (mean-value, hit-or-miss, signed hit-or-miss) і звірка з `scipy.integrate.quad`.

## Передумови

- Python ≥ 3.12
- [uv](https://docs.astral.sh/uv/) — менеджер пакетів та віртуальних оточень

Встановити uv (одноразово):

```bash
brew install uv          # macOS
# або:  curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Запуск

Усі команди виконуються з кореня репозиторію. uv автоматично створить `.venv` та встановить залежності при першому запуску.

### Завдання 1

```bash
uv run task_01/main.py
```

Виведе:
- демо обчислення решти для суми 113 двома алгоритмами;
- бенчмарк часу виконання для сум від 100 до 1 000 000.

Детальний опис, аналіз складності та висновки — у [`task_01/README.md`](task_01/README.md).

### Завдання 2

```bash
uv run task_02/main.py
```

Виведе:
- аналітичне значення інтеграла та результат `scipy.integrate.quad` як еталон;
- три варіанти Монте-Карло (mean-value, naive hit-or-miss, signed hit-or-miss) на $\sin(x)$ на $[0, 4]$;
- порівняння точності та демонстрацію провалу наївного hit-or-miss на функції зі зміною знаку.

Детальний опис, графік області інтегрування та висновки — у [`task_02/README.md`](task_02/README.md).

## Залежності

Керуються через `pyproject.toml` / `uv.lock`:

- `numpy` — векторні обчислення.
- `scipy` — `scipy.integrate.quad` як еталон.
